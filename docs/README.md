# ME Documentation Index

This folder is the product governance source of truth for **ME Branch ERP**.

ME is a **customer-facing B-end restaurant ERP / CRM / operations platform**, not a developer demo, not a mock dashboard, and not a random collection of feature pages.

After this governance pass, future UI changes must follow:
